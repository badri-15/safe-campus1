# SafeCampus

A campus safety web app built to help students quickly report incidents and access safety resources in one place.

**Live demo:** https://safe-campus1-iota.vercel.app

## Features
- Report a safety incident (location, description, category)
- View a running list of recent reports
- Quick-access safety resources and emergency contacts

## Tech Stack
- React 19
- Vite
- Deployed on Vercel

## Getting Started

```bash
git clone https://github.com/badri-15/safe-campus1.git
cd safe-campus1
npm install
npm run dev
```

## About
Built as a personal project exploring campus safety and security use cases, with a focus on simple, fast incident reporting.
